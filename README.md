# VESTRA ART LAB

مختبر إبداعي فني رقمي متعدد التخصصات مدعوم بالذكاء الاصطناعي، يستهدف طلاب كلية التربية النوعية.

## المجالات
- الملابس والنسيج.
- التربية الفنية.
- التصميم الرقمي.
- الفنون الزخرفية.

## المعمارية التقنية المعتمدة
- الواجهة: React + Vite، والنشر على Vercel.
- المصادقة: Firebase Authentication.
- قاعدة البيانات: Cloud Firestore.
- تخزين الصور والفيديوهات: Cloudinary.
- الذكاء الاصطناعي: AI Provider Adapter قابل للتبديل.
- Firebase Storage غير مستخدم في المعمارية الحالية.

### دورة رفع الوسائط
1. يختار الطالب صورة أو فيديو من واجهة الموقع.
2. يرفع التطبيق الملف إلى Cloudinary باستخدام آلية رفع آمنة.
3. تستقبل الواجهة استجابة Cloudinary وتستخرج secure_url وpublic_id ونوع المورد وبياناته.
4. يحفظ التطبيق في Firestore مستند metadata يحتوي الرابط ومعرّف الملف ومالكه والمشروع المرتبط به.
5. يعرض التطبيق الوسائط لاحقاً بقراءة الرابط من Firestore.
6. حذف الملفات من Cloudinary يتم عبر خادم موثوق يتحقق من هوية المستخدم وملكيته.

Firestore يحفظ البيانات والروابط فقط، ولا يحفظ بايتات الصور والفيديوهات.

## إعداد التجربة الافتراضية المباشرة
- أضف `DECART_API_KEY` في Vercel Project → Settings → Environment Variables (Production وPreview).
- المفتاح دائم وسري ويُستخدم داخل `api/realtime-token.js` فقط؛ لا تضفه إلى متغير يبدأ بـ `VITE_` ولا إلى GitHub.
- يحتاج endpoint إلى `VITE_FIREBASE_API_KEY` الموجود أصلاً للتحقق من جلسة Firebase قبل إصدار Decart client token قصير العمر.
- بعد إضافة المفتاح، أعد نشر المشروع. تجربة الملابس تستخدم الكاميرا وWebRTC، ويجب أن يوافق المستخدم صراحة على إرسال بث الكاميرا وصورة القطعة إلى Decart.
- قد يستهلك تشغيل التجربة رصيد Decart بحسب مدة الفيديو؛ أوقف الجلسة عند الانتهاء.

## قواعد العمل
- اقرأ README وdocs/AI_HANDOFF.md وdocs/PROJECT_STATUS.md قبل التعديل.
- حدّث PROJECT_STATUS.md بعد كل مرحلة.
- لا تحذف وظيفة قائمة دون موافقة صاحب المشروع.
- لا تضع مفاتيح سرية أو Cloudinary API Secret أو Firebase Admin credentials في المستودع.
- لا تعتبر أي أداة مكتملة لمجرد ظهور واجهتها؛ اختبرها وظيفياً.
- لا تستخدم PHP أو MySQL أو Firebase Storage في التصميم الحالي دون قرار جديد صريح.
- لا تدّعِ نجاح خدمة أو اختبار دون تنفيذه فعلياً.

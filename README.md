# VESTRA ART LAB

**مختبر إبداعي فني رقمي متعدد التخصصات مدعوم بالذكاء الاصطناعي**

مساحة تعليمية وإبداعية تستهدف طلاب كلية التربية النوعية، وتجمع بين إنتاج التصميمات الرقمية وتحليلها والتجريب الفني والتعلم القائم على المشروعات.

## الرؤية
تمكين الطلاب من تحويل أفكارهم إلى أعمال فنية وتصميمية رقمية، والاستفادة من الذكاء الاصطناعي في التوليد والتحليل والتطوير، مع بقاء الطالب صاحب القرار الإبداعي.

## المجالات المستهدفة
- الملابس والنسيج.
- التربية الفنية.
- التصميم الرقمي.
- الفنون الزخرفية.

## الوظائف الرئيسية المخطط لها
مساحة الطالب، إدارة المشروعات والملفات، معمل التصميم، لوحات الإلهام، مكتبة الخامات، استوديو الألوان، مساعد AI للتوليد والتحليل، تجربة الملابس الافتراضية، التقييم الفني، والتحليلات البحثية.

## التقنية المعتمدة
- React + Vite.
- Firebase Authentication وCloud Firestore وStorage بعد إعداد القواعد.
- AI Provider Adapter مرن قابل لتبديل المزود.
- واجهة عربية RTL ومتجاوبة.

## تشغيل المشروع محلياً
```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:
```bash
npm run build
npm run preview
```

## قواعد العمل

- حدّث PROJECT_STATUS.md بعد كل مرحلة.

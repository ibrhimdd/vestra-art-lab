# VESTRA ART LAB

**مختبر إبداعي فني رقمي متعدد التخصصات مدعوم بالذكاء الاصطناعي**

مساحة تعليمية وإبداعية تستهدف طلاب كلية التربية النوعية، وتجمع بين إنتاج التصميمات الرقمية وتحليلها والتجريب الفني والتعلم القائم على المشروعات.

## الرؤية
تمكين الطلاب من تحويل أفكارهم إلى أعمال فنية وتصميمية رقمية، والاستفادة من الذكاء الاصطناعي في التوليد والتحليل والتطوير، مع بقاء الطالب صاحب القرار الإبداعي.

## المجالات المستهدفة
- الملابس والنسيج.
- التربية الفنية.
- التصميم الرقمي.
- الفنون الزخرفية.

## الوظائف المخطط لها
1. حسابات الطلاب ومساحة عمل شخصية.
2. إنشاء المشروعات وتنظيمها وحفظها.
3. معمل تصميم ومكتبة خامات وإلهام بصري.
4. مساعد ذكاء اصطناعي لتوليد التصميمات وتحليلها.
5. تجربة افتراضية للملابس، دون ادعاء محاكاة دقيقة للخامات أو المقاسات ثلاثية الأبعاد ما لم تنفذ وتختبر فعلياً.
6. أدوات تقييم وقياس بحثي وتقارير.

## التوجه التقني المعتمد
- Frontend: React + Vite.
- Database / Authentication: Firebase Authentication وCloud Firestore.
- AI: طبقة تكامل مرنة تسمح بتبديل المزود.
- الواجهة: العربية وRTL مع تصميم متجاوب.

هذه قرارات معتمدة وليست دليلاً على أن الخدمات تم إعدادها أو اختبارها بعد.

## 2. معلومات المستودع والقرارات
- Repository: https://github.com/ibrhimdd/vestra-art-lab
- Default branch: main
- Frontend: React + Vite على Vercel.
- Authentication: Firebase Authentication.
- Database: Cloud Firestore.
- Media storage: Cloudinary (رفع الصور يعمل وفق اختبار صاحب المشروع).
- Firebase Storage: غير مستخدم في التصميم الحالي.
- PHP وMySQL: غير مستخدمين في التصميم الحالي.
- AI: Flexible provider adapter.
- واجهة عربية RTL.

## 8. سجل القرارات
### 2026-11-18 — اعتماد Cloudinary للوسائط
- Cloudinary لتخزين الصور والفيديوهات وإرجاع روابط HTTPS.
- Firestore لحفظ البيانات والروابط والmetadata فقط.
- Firebase Storage غير مستخدم.
- لا PHP ولا MySQL في المعمارية الحالية.

### 2026-11-19 — تأكيد معرض الوسائط
- أكد صاحب المشروع أن معاينة الصور والبحث والتصفية والتنزيل في معرض المشروع تعمل بعد النشر.

### 2026-11-19 — تأكيد الاختبارات الأساسية
- أكد صاحب المشروع نجاح إنشاء مشروع وتعديله وحذفه.
- أكد نجاح رفع صورة إلى مشروع وحفظها وعرضها.
- تم إصلاح permission-denied عبر قواعد Firestore مقيدة بملكية المستخدم.
- ما زال اختبار الفيديو وحذف الأصل من Cloudinary مطلوباً.

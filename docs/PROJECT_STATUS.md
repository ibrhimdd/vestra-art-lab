## 7. الخطوة التالية المتفق عليها
1. صاحب المشروع ينشئ حساب Cloudinary ويرسل Cloud Name وإعدادات الرفع غير السرية.
2. لا ترسل API Secret أو مفاتيح خاصة في المحادثة أو GitHub.
3. افحص ملفات Firebase الحالية وFirestore rules وpackage.json قبل تعديل الكود.
4. حدد آلية الرفع: signed upload عبر endpoint موثوق للإنتاج، أو unsigned preset مقيد للاختبار.
5. نفّذ رفع صورة تجريبية، واحفظ secure_url وpublic_id وresource_type والمالك ومعرّف المشروع في Firestore.
6. اختبر إعادة عرض الصورة، ثم الفيديو، ثم الحذف.
7. شغّل npm run build وراجع GitHub Actions.
8. حدّث سجل الحالة بعد الاختبار.

## 8. سجل القرارات
### 2026-11-18 — اعتماد Cloudinary للوسائط
- Cloudinary لتخزين الصور والفيديوهات وإرجاع روابط HTTPS.
- Firestore لحفظ البيانات والروابط والmetadata فقط.
- Firebase Storage غير مستخدم.
- لا PHP ولا MySQL في المعمارية الحالية.
- لم يتم إنشاء حساب Cloudinary أو ربط API بعد؛ التنفيذ ينتظر إعدادات الحساب.

### 2026-11-18 — حالة Firebase
- Firebase SDK وAuth Context وربط إنشاء المشروعات موثقة كإضافات سابقة.
- نشر قواعد Firestore والاختبارات الحقيقية لم يتم تأكيدهما.

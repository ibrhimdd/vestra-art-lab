- Frontend: React + Vite على Vercel.

- Database: Cloud Firestore.
- Media storage: Cloudinary (رفع الصور يعمل وفق اختبار صاحب المشروع).

- AI: Flexible provider adapter.
- واجهة عربية RTL.

## 8. سجل القرارات
### 2026-11-18 — اعتماد Cloudinary للوسائط
- Cloudinary لتخزين الصور والفيديوهات وإرجاع روابط HTTPS.
- Firestore لحفظ البيانات والروابط والmetadata فقط.
- Firebase Storage غير مستخدم.
- لا PHP ولا MySQL في المعمارية الحالية.

### 2026-11-19 — تأكيد معرض الوسائط
- أكد صاحب المشروع أن معاينة الصور والبحث والتصفية والتنزيل في معرض المشروع تعمل بعد النشر.

### 2026-11-19 — تأكيد لوحة الإلهام وتنفيذ استوديو الألوان
- أكد صاحب المشروع أن لوحة الإلهام تعمل بعد النشر.
- أضيف Color Studio: تحليل ألوان الصور محلياً داخل المتصفح عبر Canvas، تعديل وإضافة/حذف الألوان، نسخ HEX، وحفظ اللوحات في users/{uid}.colorPalettes.
- استوديو الألوان لم يخضع بعد لاختبار المستخدم أو إعادة تحميل البيانات.

### 2026-11-19 — تأكيد الاختبارات الأساسية
- أكد صاحب المشروع نجاح إنشاء مشروع وتعديله وحذفه.
- أكد نجاح رفع صورة إلى مشروع وحفظها وعرضها.
- تم إصلاح permission-denied عبر قواعد Firestore مقيدة بملكية المستخدم.
- ما زال اختبار الفيديو وحذف الأصل من Cloudinary مطلوباً.

### 2026-11-19 — إضافة أدوات المختبر ودمجها
- أضيفت MaterialsLibrarySection: تصنيف وبحث وإضافة وتعديل وحذف الخامات مع رفع الصور إلى Cloudinary وحفظ البيانات في users/{uid}.materials.
- أضيف IdeaGeneratorSection بقوالب توليد محلية قابلة للتخصيص، ثم أضيف حفظ الأفكار في users/{uid}.creativeIdeas.
- أضيف DesignAnalyzerSection لتحليل الأبعاد والإضاءة والتباين والألوان محلياً باستخدام Canvas. النتائج إرشادية وليست تقييماً فنياً.
- أضيف VirtualTryOnSection كمساحة لاختيار الإطلالات وحفظ جلسات التنسيق؛ لا تنفذ توليد ارتداء واقعي حتى ربط محرك AI.
- تم دمج الأدوات الأربع في main عبر PR #2، commit 11ccc362.

# VESTRA ART LAB — ROADMAP & FEATURE CATALOG

هذا الملف خطة التنفيذ التفصيلية. أي عنصر يظل مخططاً حتى ينفذ ويختبر وتحدث حالته في PROJECT_STATUS.md.

## القرارات التقنية الحاكمة
- React + Vite للواجهة، والنشر على Vercel.
- Firebase Authentication للمصادقة.
- Cloud Firestore لبيانات المستخدمين والمشروعات والبيانات الوصفية وروابط الوسائط.
- Cloudinary لتخزين الصور والفيديوهات وإرجاع روابطها.
- لا تستخدم Firebase Storage أو PHP أو MySQL في التصميم الحالي.
- لا تحفظ محتوى الصور والفيديوهات داخل Firestore؛ احفظ الروابط والبيانات الوصفية فقط.
- لا تضع Cloudinary API Secret أو Firebase Admin credentials في كود المتصفح أو GitHub.

## خريطة المراحل

### المرحلة 1 — تأسيس التطبيق والهوية
- React + Vite وواجهة عربية RTL ومتجاوبة.
- لوحة المختبر والأقسام الرئيسية ونظام التصميم.
- CI لبناء نسخة الإنتاج.
**معيار الإنجاز:** build ناجح ومراجعة الهاتف والحاسوب وعدم وجود أخطاء حرجة.

### المرحلة 2 — الحسابات ومساحة الطالب <span>مكتملة جزئياً</span>
- إنشاء حساب وتسجيل دخول وخروج واستعادة كلمة المرور.
- ملف شخصي واختيار التخصص وإعدادات الحساب.
- لوحة شخصية وقائمة مشروعات ونشاط حديث وإشعارات.
- Firebase Authentication وCloud Firestore.
**معيار الإنجاز:** اختبار الحسابات والجلسات وحماية الصفحات، مع قواعد Firestore منشورة ومختبرة.

### المرحلة 3 — المشروعات والوسائط (Firestore + Cloudinary) — قيد التنفيذ
**تم اختباره:** إنشاء وتعديل وحذف المشروعات، ورفع صورة وحفظ مرجعها في Firestore بعد إصلاح قواعد الصلاحيات.

**المتبقي في المرحلة:** معرض مرئي، بحث وتصفية، معاينة، تنزيل، اختبار فيديو، ومراجعة أمان الرفع والحذف.
- إنشاء وتعديل وحذف مشروع، وصف وأهداف ومجال وحالة.
- حفظ مراحل المشروع وسجل الإصدارات.
- رفع الصور والرسومات والفيديوهات والملفات المدعومة إلى Cloudinary.
- حفظ secure_url وpublic_id وresource_type وformat والحجم والأبعاد وبيانات المالك والمشروع في Firestore.
- إعادة عرض الملفات من روابط Cloudinary عند فتح المشروع.
- معرض وسائط داخل كل مشروع مع بطاقات مصغرة للصور والفيديو.
- تصفية حسب الكل/الصور/الفيديو والبحث باسم الملف.
- معاينة الصور بحجم كبير وتشغيل الفيديو داخل نافذة معاينة.
- إتاحة فتح الملف أو تنزيله من رابط Cloudinary.
- استخدام signed upload عبر endpoint موثوق للإنتاج؛ unsigned preset مقيد للاختبار فقط وبعد تقييم المخاطر.
- حذف الملف من Cloudinary عبر endpoint خادمي يتحقق من هوية وملكية المستخدم، ثم تحديث Firestore.
- التحقق من أنواع الملفات وأحجامها وإظهار تقدم الرفع وحالات الخطأ.
**معيار الإنجاز:** نجاح دورة الصورة والفيديو، المعاينة والبحث والتصفية والتنزيل، واختبار الصلاحيات والحذف وعدم ترك ملفات يتيمة.

### المرحلة 4 — معمل التصميم
- Moodboard لتجميع المراجع والأفكار.
- Color Studio لاستخراج الألوان وتكوين لوحات لونية.
- Pattern Explorer لاستكشاف النقوش والتكرارات.
- Materials Library لمكتبة الخامات والأنسجة.
- مساحة عمل لتجميع العناصر وملاحظات ومقارنة نسخ التصميم.
**معيار الإنجاز:** حفظ كل لوحة وأصولها داخل مشروع الطالب وإمكانية إعادة فتحها.

### المرحلة 5 — مساعد الذكاء الاصطناعي
- توليد مفاهيم وبدائل تصميم وأوصاف واقتراحات ألوان.
- تحليل التصميم وإظهار نقاط القوة وفرص التحسين.
- Provider Adapter بعقود موحدة وموصلات مستقلة ومزود قابل للتبديل.
- مفاتيح سرية خادمية وحدود استخدام وسجل أخطاء.
**معيار الإنجاز:** اختبار تبديل المزود والفشل والمهلة وعدم تسرب المفاتيح.

### المرحلة 6 — أدوات المجالات الفنية
- الملابس والنسيج: أفكار أزياء وتنسيق القطع ولوحات ألوان ونقوش وخامات.
- التربية الفنية: تكوين ورسم وتمارين إبداعية وتحليل العمل.
- التصميم الرقمي: ملصقات وهويات بصرية وشبكات تخطيط وتباين.
- الفنون الزخرفية: وحدات زخرفية وتناظر وتكرار وإيقاع وبدائل ألوان.
**معيار الإنجاز:** لكل أداة مدخلات ومخرجات واضحة واختبار وظيفي.

### المرحلة 7 — التجربة الافتراضية
- مراجعة مصدر المشروع السابق واعتمادياته وتراخيصه.
- فصل محرك التجربة عن واجهة المختبر.
- دمج تجربة الملابس ضمن مجال الملابس والنسيج.
- حفظ مرجع القطعة ونتائج التجربة داخل مشروع الطالب.
**معيار الإنجاز:** اختبار الكاميرا والرفع والنتائج والأخطاء.

### المرحلة 8 — التقييم والقياس البحثي
- Rubrics للتقييم الفني والتغذية الراجعة.
- اختبارات قبلية وبعدية حسب بروتوكول الدراسة.
- مقاييس الانخراط ومتابعة تقدم الطالب.
- تقارير فردية ومجمعة وتصدير.
**معيار الإنجاز:** تعريف المؤشرات ومعادلاتها ومصدر كل قيمة واختبار دقة الحسابات.

### المرحلة 9 — الإدارة والإطلاق
- إدارة المستخدمين والتخصصات والمكتبات والأدوار.
- سجل تدقيق للعمليات الحساسة.
- اختبارات أمان وخصوصية وإمكانية وصول.
- تحسين الأداء والنسخ الاحتياطي والمراقبة والنشر.
**معيار الإنجاز:** قائمة إطلاق معتمدة ونسخة إنتاج قابلة للاستخدام.

## ترتيب التنفيذ الحالي
1. استكمال معرض الوسائط والبحث والتصفية والمعاينة.
2. اختبار الفيديو والتنزيل على الهاتف والحاسوب.
3. مراجعة أمان Upload Preset وآلية الرفع للإنتاج.
4. بدء Moodboard ثم Color Studio ثم Materials Library.
5. الانتقال إلى مساعد الذكاء الاصطناعي بعد تحديد مزود الخدمة.

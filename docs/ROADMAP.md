# VESTRA ART LAB — ROADMAP & FEATURE CATALOG

هذا الملف خطة التنفيذ التفصيلية. أي عنصر يظل مخططاً حتى ينفذ ويختبر وتحدث حالته في PROJECT_STATUS.md.

## القرارات التقنية الحاكمة
- React + Vite للواجهة، والنشر على Vercel.
- Firebase Authentication للمصادقة.
- Cloud Firestore لبيانات المستخدمين والمشروعات والبيانات الوصفية وروابط الوسائط.
- Cloudinary لتخزين الصور والفيديوهات وإرجاع روابطها.
- لا تستخدم Firebase Storage أو PHP أو MySQL في التصميم الحالي.
- لا تحفظ محتوى الصور والفيديوهات داخل Firestore؛ احفظ الروابط والبيانات الوصفية فقط.
- لا تضع Cloudinary API Secret أو Firebase Admin credentials في كود المتصفح أو GitHub.

## خريطة المراحل

### المرحلة 1 — تأسيس التطبيق والهوية
- React + Vite وواجهة عربية RTL ومتجاوبة.
- لوحة المختبر والأقسام الرئيسية ونظام التصميم.
- CI لبناء نسخة الإنتاج.
**معيار الإنجاز:** build ناجح ومراجعة الهاتف والحاسوب وعدم وجود أخطاء حرجة.

### المرحلة 2 — الحسابات ومساحة الطالب <span>مكتملة جزئياً</span>
- إنشاء حساب وتسجيل دخول وخروج واستعادة كلمة المرور.
- ملف شخصي واختيار التخصص وإعدادات الحساب.
- لوحة شخصية وقائمة مشروعات ونشاط حديث وإشعارات.
- Firebase Authentication وCloud Firestore.
**معيار الإنجاز:** اختبار الحسابات والجلسات وحماية الصفحات، مع قواعد Firestore منشورة ومختبرة.

### المرحلة 3 — المشروعات والوسائط (Firestore + Cloudinary) — مكتملة وظيفياً مع اختبارات متبقية
**تم اختباره من صاحب المشروع:** إنشاء وتعديل وحذف المشروعات، رفع صورة، ومعرض الوسائط مع المعاينة والبحث والتصفية والتنزيل.

**المتبقي للتحقق:** رفع فيديو فعلي، مراجعة أمان الرفع، والحذف الفعلي من Cloudinary.
- إنشاء وتعديل وحذف مشروع، وصف وأهداف ومجال وحالة.
- حفظ مراحل المشروع وسجل الإصدارات.
- رفع الصور والرسومات والفيديوهات والملفات المدعومة إلى Cloudinary.
- حفظ secure_url وpublic_id وresource_type وformat والحجم والأبعاد وبيانات المالك والمشروع في Firestore.
- إعادة عرض الملفات من روابط Cloudinary عند فتح المشروع.
- معرض وسائط داخل كل مشروع مع بطاقات مصغرة للصور والفيديو.
- تصفية حسب الكل/الصور/الفيديو والبحث باسم الملف.
- معاينة الصور بحجم كبير وتشغيل الفيديو داخل نافذة معاينة.
- إتاحة فتح الملف أو تنزيله من رابط Cloudinary.
- استخدام signed upload عبر endpoint موثوق للإنتاج؛ unsigned preset مقيد للاختبار فقط وبعد تقييم المخاطر.
- حذف الملف من Cloudinary عبر endpoint خادمي يتحقق من هوية وملكية المستخدم، ثم تحديث Firestore.
- التحقق من أنواع الملفات وأحجامها وإظهار تقدم الرفع وحالات الخطأ.
**معيار الإنجاز:** نجاح دورة الصورة والفيديو، المعاينة والبحث والتصفية والتنزيل، واختبار الصلاحيات والحذف وعدم ترك ملفات يتيمة.

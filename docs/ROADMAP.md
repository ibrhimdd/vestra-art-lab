# VESTRA ART LAB — ROADMAP & FEATURE CATALOG

هذا الملف هو خطة التنفيذ التفصيلية وقائمة الأدوات والمميزات المستهدفة. أي عنصر هنا يظل "مخططاً" حتى ينفذ ويختبر وتحدث حالته في PROJECT_STATUS.md.

## خريطة المراحل

### المرحلة 1 — تأسيس التطبيق والهوية
- إعداد React + Vite وبيئة التطوير.
- واجهة عربية RTL ومتجاوبة.
- لوحة المختبر والأقسام الرئيسية.
- نظام ألوان وخطوط ومكونات أساسية.
- CI لبناء نسخة الإنتاج.
**معيار الإنجاز:** build ناجح، مراجعة الهاتف والحاسوب، وعدم وجود أخطاء حرجة.

### المرحلة 2 — الحسابات ومساحة الطالب
- إنشاء حساب، تسجيل دخول وخروج، استعادة كلمة المرور.
- ملف شخصي واختيار التخصص وإعدادات الحساب.
- لوحة شخصية وقائمة مشروعات ونشاط حديث وإشعارات.
- Firebase Authentication وCloud Firestore.
**معيار الإنجاز:** اختبار التسجيل والدخول والخروج واستعادة كلمة المرور وحماية الصفحات واسترجاع الجلسة.

### المرحلة 3 — المشروعات والملفات
- إنشاء وتعديل وحذف مشروع، وصف وأهداف ومجال وحالة.
- حفظ مراحل المشروع وسجل الإصدارات.
- رفع الصور والرسومات والمستندات ومعاينتها وتنظيمها.
- Firestore للبيانات وFirebase Storage للملفات مع قواعد صلاحيات.
**معيار الإنجاز:** لا يستطيع طالب الوصول لمشروعات أو ملفات طالب آخر، مع اختبار الرفع والتنزيل والحذف.

### المرحلة 4 — معمل التصميم
- Moodboard لتجميع المراجع والأفكار.
- Color Studio لاستخراج الألوان وتكوين لوحات لونية.
- Pattern Explorer لاستكشاف النقوش والتكرارات.
- Materials Library لمكتبة الخامات والأنسجة.
- مساحة عمل لتجميع العناصر وملاحظات ومقارنة نسخ التصميم.
**معيار الإنجاز:** حفظ كل لوحة وأصلها داخل مشروع الطالب وإمكانية إعادة فتحها.

### المرحلة 5 — مساعد الذكاء الاصطناعي
- توليد مفاهيم وبدائل تصميم وأوصاف واقتراحات ألوان.
- تحليل التصميم وإظهار نقاط القوة وفرص التحسين.
- Provider Adapter بعقود موحدة وموصلات مستقلة ومزود قابل للتبديل.
- مفاتيح سرية خادمية وحدود استخدام وسجل أخطاء.
**معيار الإنجاز:** اختبار تبديل المزود والفشل والمهلة وعدم تسرب المفاتيح. المخرجات مقترحات وليست أحكاماً نهائية.

### المرحلة 6 — أدوات المجالات الفنية
- **الملابس والنسيج:** أفكار أزياء، تنسيق القطع، لوحات ألوان، نقوش وخامات.
- **التربية الفنية:** تكوين ورسم، تمارين إبداعية، تحليل عناصر العمل وتوثيق المراحل.
- **التصميم الرقمي:** ملصقات وهويات بصرية وشبكات تخطيط وخطوط وتباين.
- **الفنون الزخرفية:** وحدات زخرفية وتناظر وتكرار وإيقاع وبدائل ألوان.
**معيار الإنجاز:** لكل أداة مدخلات ومخرجات واضحة واختبار وظيفي.

### المرحلة 7 — التجربة الافتراضية
- مراجعة مصدر المشروع السابق واعتمادياته وتراخيصه.
- فصل محرك التجربة عن واجهة المختبر.
- دمج تجربة الملابس ضمن مجال الملابس والنسيج.
- حفظ مرجع القطعة ونتائج التجربة داخل مشروع الطالب عند الإمكان.
- عدم ادعاء محاكاة دقيقة للخامات أو المقاسات ثلاثية الأبعاد دون إثبات.
**معيار الإنجاز:** اختبار الكاميرا والرفع والنتائج والأخطاء.

### المرحلة 8 — التقييم والقياس البحثي
- Rubrics للتقييم الفني حسب التخصص.
- تغذية راجعة من المعلم/المشرف.
- اختبارات قبلية وبعدية حسب بروتوكول الدراسة.
- مقاييس الانخراط ومتابعة تقدم الطالب.
- تقارير فردية ومجمعة وتصدير.
**معيار الإنجاز:** تعريف المؤشرات ومعادلاتها ومصدر كل قيمة واختبار دقة الحسابات.

### المرحلة 9 — الإدارة والإطلاق
- إدارة المستخدمين والتخصصات والمكتبات والأدوار.
- سجل تدقيق للعمليات الحساسة.
- اختبارات أمان وخصوصية وإمكانية وصول.
- تحسين الأداء والنسخ الاحتياطي والمراقبة والنشر.
**معيار الإنجاز:** قائمة إطلاق معتمدة ونسخة إنتاج قابلة للاستخدام.

## طريقة إدارة التنفيذ
1. تنفيذ مرحلة واحدة أو نطاق صغير قابل للاختبار في كل مرة.
2. كتابة معايير قبول قبل البدء.
3. تنفيذ الواجهة والخدمات وقواعد الأمان معاً عند الحاجة.
4. تشغيل build والاختبارات المناسبة.
5. توثيق ما تم فعلياً وما لم يتم.
6. تحديث PROJECT_STATUS.md وPROJECT_STRUCTURE.md.
7. لا يتم دمج فرع التنفيذ في main إلا بعد موافقة صاحب المشروع.
